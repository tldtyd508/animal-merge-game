# 🐾 동물 합치기 (Merge Animals)

수박게임(Suika Game) 스타일의 동물 합치기 캐주얼 웹 게임

## 시작하기

```bash
npm install
npm run dev
```

## 게임 방법

- 마우스/터치로 좌우 이동, 클릭/탭으로 동물 드롭
- 같은 동물이 만나면 한 단계 큰 동물로 진화
- 개미 → 쥐 → 햄스터 → 토끼 → 고양이 → 강아지 → 여우 → 곰 → 사자 → 코끼리 → 공룡 🦕
- 동물이 빨간 점선 위로 넘치면 게임 오버

## 기술 스택

- Vite + React
- HTML5 Canvas 2D
- 자체 물리엔진
